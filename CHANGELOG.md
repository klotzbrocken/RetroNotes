# Changelog

## 1.0 – 2026-10-12
- First release: Notes in the style of OS X 10.8 Mountain Lion, data read from and written back to the system Notes app (JXA/osascript)
- Accounts, folders, note list, rich-text editor on lined paper, single-note windows, full-screen mode
- Image attachments by drag and drop, backup and restore (`manifest.json` + one `.html` per note)
- Signed and notarized DMG via `release.sh`
